## Chạy kiểm tra

Trong `frontend/`:

```bash
npm install
npm run build
npm run dev
```

Mở `http://localhost:5173/` (Vite proxy backend port `8080`). Bộ nguồn được kiểm tra cú pháp JavaScript của các script Vue/Router và phân tích CSS tĩnh. Chưa xác nhận build Vite hoặc tích hợp API với MySQL trong môi trường đóng gói vì thư mục `node_modules` không có sẵn.
